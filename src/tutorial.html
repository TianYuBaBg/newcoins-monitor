1准备钱包
PRL 是 Pearl 链的原生币，需要官方钱包才能接收挖矿收益。

下载地址：pearl.org/wallet（Windows / Linux 版本均有）
安装后创建新地址，格式示例：
prl1pwqwmgfnsfn2d78453v2p4sd8dewq09e9pjgc7jkwsqt4lxmcljgq9kuj8d

注意：记好助记词！这是恢复钱包的唯一凭证，丢失无法找回。
2注册矿池
推荐矿池：AlphaPool — pearl.alphapool.tech

访问矿池网站，用钱包地址注册账号，设置最小支付阈值（推荐 10 PRL）。
矿池会实时显示你的算力、提交份额和待支付余额。
3下载挖矿软件
PRL 使用 NoisyGEMM 算法，推荐以下矿工：

Windows lolMiner 或 SRBMiner
Linux lolMiner（推荐 WSL 环境运行）

解压后找到配置文件或 batch 文件进行下一步设置。
4配置并启动挖矿
以 lolMiner 为例，创建启动脚本：
提示：Windows 用户建议在 WSL (Ubuntu) 下运行，稳定性更好。我们实测 GPU 跑在 WSL 环境下，连续运行数月无故障。
./lolMiner --coin PRL --pool pearl.alphapool.tech:port --user 你的钱包地址

启动后观察输出：
✓ 连接矿池成功 → 开始提交 shares
✓ 算力稳定在预期范围（参考：实测 ~68 TH/s）
✓ GPU 温度 ~66°C，功耗 ~220W
5交易所卖币
PRL 已上线 SafeTrade 交易所，交易对 PRL/USDT。

步骤：
1. 注册 SafeTrade（safe.trade），完成基础认证
2. 矿池提现 → 填入 SafeTrade 充值地址（PRL 网络）
3. 到账后在 PRL/USDT 市价或挂单卖出
进阶：我们开发了自动卖币机器人，到账自动市价卖出，无需手动操作。支持设置阶梯卖价（如 $1.50 卖 50%、$2.00 卖 80%）和止损价。
